
# Basic Calculator Using C

## 1. Project Overview
The Basic Calculator is a console-based application developed using C. It performs basic arithmetic operations based on user input.

## 2. Objectives
- Perform addition, subtraction, multiplication, and division.
- Accept numerical input from users.
- Display calculated results.
- Handle division by zero.

## 3. Tools & Technologies Used
- C Programming Language
- GCC Compiler
- VS Code / Code::Blocks
- Command Prompt / Terminal

## 4. Features Implemented
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Menu-driven interface
- Multiple calculations

## 5. Application Workflow
1. Display the calculator menu.
2. Select an arithmetic operation.
3. Enter two numbers.
4. Perform the selected calculation.
5. Display the result.
6. Continue or exit.

## 6. How to Run the Project
1. Save the source code as `basic_calculator.c`.
2. Compile using: `gcc basic_calculator.c -o calculator`
3. Run the generated program.

## 7. Expected Output
The program displays the selected arithmetic operation and its calculated result.

## 8. Conclusion
The project demonstrates basic arithmetic operations and fundamental C programming concepts through a simple calculator application.
