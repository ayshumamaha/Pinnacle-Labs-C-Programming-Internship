
# Basic E-commerce System Using C

## 1. Project Overview
The Basic E-commerce System is a console-based shopping application developed using C. It allows users to browse products, select quantities, manage a shopping cart, and calculate the final bill.

## 2. Objectives
- Display available products.
- Allow product selection.
- Accept product quantities.
- Manage shopping cart information.
- Calculate the purchase total.

## 3. Tools & Technologies Used
- C Programming Language
- GCC Compiler
- VS Code / Code::Blocks
- Command Prompt / Terminal

## 4. Features Implemented
- Product catalogue
- Product selection
- Quantity selection
- Shopping cart
- Automatic bill calculation
- Purchase summary

## 5. Application Workflow
1. Display available products.
2. Select a product.
3. Enter the required quantity.
4. Add items to the cart.
5. Calculate the total amount.
6. Display the shopping bill.

## 6. How to Run the Project
1. Save the code as `ecommerce_system.c`.
2. Compile using: `gcc ecommerce_system.c -o ecommerce`
3. Run the generated program.

## 7. Expected Output
The program displays the product catalogue, accepts customer selections, and generates a purchase bill.
