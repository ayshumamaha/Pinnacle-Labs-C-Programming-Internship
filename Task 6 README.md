# Number Converter Using C

## 1. Project Overview
The Number Converter is a console-based application developed using C. It converts numbers between decimal, binary, and hexadecimal number systems.

## 2. Objectives
- Convert decimal numbers into binary.
- Convert binary numbers into decimal.
- Convert decimal numbers into hexadecimal.
- Convert hexadecimal numbers into decimal.

## 3. Tools & Technologies Used
- C Programming Language
- GCC Compiler
- VS Code / Code::Blocks
- Command Prompt / Terminal

## 4. Features Implemented
- Decimal-to-binary conversion
- Binary-to-decimal conversion
- Decimal-to-hexadecimal conversion
- Hexadecimal-to-decimal conversion
- Input validation

## 5. Application Workflow
1. Display conversion options.
2. Select the required conversion.
3. Enter a number.
4. Validate the input.
5. Perform the conversion.
6. Display the result.

## 6. How to Run the Project
1. Save the code as `number_converter.c`.
2. Compile using: `gcc number_converter.c -o converter`
3. Run the generated program.

## 7. Expected Output
The program displays the converted number according to the selected conversion option.

## 8. Conclusion
The project demonstrates number system conversions and mathematical operations using C programming.
