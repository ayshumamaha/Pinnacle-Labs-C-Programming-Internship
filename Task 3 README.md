# Online Quiz Application Using C

## 1. Project Overview
The Online Quiz Application is a console-based program developed using C. It displays multiple-choice questions, evaluates answers, and calculates the user's score.

## 2. Objectives
- Display quiz questions.
- Accept user answers.
- Evaluate answers automatically.
- Calculate the final score.

## 3. Tools & Technologies Used
- C Programming Language
- GCC Compiler
- VS Code / Code::Blocks
- Command Prompt / Terminal

## 4. Features Implemented
- Multiple-choice questions
- Answer evaluation
- Automatic scoring
- Final result display
- Basic input handling

## 5. Application Workflow
1. Start the quiz.
2. Display each question and options.
3. Accept the user's answer.
4. Compare it with the correct answer.
5. Update the score.
6. Display the final result.

## 6. How to Run the Project
1. Save the code as `online_quiz.c`.
2. Compile using: `gcc online_quiz.c -o quiz`
3. Run the generated program.

## 7. Expected Output
The program displays quiz questions, accepts answers, and shows the final score out of five.

## 8. Conclusion
The project demonstrates how C programming can be used to develop a simple quiz application with automatic answer evaluation and scoring.
