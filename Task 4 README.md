# ATM Simulator Using C

## 1. Project Overview
The ATM Simulator is a console-based application developed using C. It simulates basic ATM operations such as balance enquiry, deposits, withdrawals, and transaction history.

## 2. Objectives
- Simulate basic ATM operations.
- Implement PIN verification.
- Manage account balance.
- Record transactions during execution.

## 3. Tools & Technologies Used
- C Programming Language
- GCC Compiler
- VS Code / Code::Blocks
- Command Prompt / Terminal

## 4. Features Implemented
- PIN verification
- Balance enquiry
- Cash deposit
- Cash withdrawal
- Transaction history
- Insufficient-balance validation

## 5. Application Workflow
1. Enter the predefined PIN.
2. Access the ATM menu.
3. Select a banking operation.
4. Process the transaction.
5. Update the balance.
6. View transaction history or exit.

## 6. How to Run the Project
1. Save the code as `atm_simulator.c`.
2. Compile using: `gcc atm_simulator.c -o atm`
3. Run the generated program.
4. Use the sample PIN: `1234`.

## 7. Expected Output
The program displays the ATM menu and allows users to perform basic banking transactions.

## 8. Conclusion
The project demonstrates basic banking operations and transaction processing using C programming.
