# Banking System Using C

## 1. Project Overview
The Banking System is a console-based application developed using C. It supports customer account creation, deposits, withdrawals, and balance enquiries.

## 2. Objectives
- Create customer accounts.
- Manage account balances.
- Process deposits and withdrawals.
- Display customer account information.

## 3. Tools & Technologies Used
- C Programming Language
- GCC Compiler
- VS Code / Code::Blocks
- Command Prompt / Terminal

## 4. Features Implemented
- Account creation
- Account number management
- Deposit operations
- Withdrawal operations
- Balance enquiry
- Multiple customer accounts

## 5. Application Workflow
1. Display the banking menu.
2. Create a customer account.
3. Enter the account number for transactions.
4. Process deposits or withdrawals.
5. Update the balance.
6. Display account information.

## 6. How to Run the Project
1. Save the code as `banking_system.c`.
2. Compile using: `gcc banking_system.c -o banking`
3. Run the generated program.

## 7. Expected Output
The program allows users to create accounts and perform basic banking transactions.

## 8. Conclusion
The project demonstrates account management and financial transaction processing using structures and arrays in C.
