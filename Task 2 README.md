# Text-Based Adventure Game Using C

## 1. Project Overview
The Text-Based Adventure Game is an interactive console application developed using C. Players make choices to explore different story paths and outcomes.

## 2. Objectives
- Develop an interactive text-based game.
- Accept player decisions.
- Display different story outcomes.
- Apply conditional statements and logical operations.

## 3. Tools & Technologies Used
- C Programming Language
- GCC Compiler
- VS Code / Code::Blocks
- Command Prompt / Terminal

## 4. Features Implemented
- Story-based gameplay
- Interactive choices
- Multiple story paths
- Different outcomes
- Input validation

## 5. Application Workflow
1. Display the game introduction.
2. Present available choices.
3. Accept the player's selection.
4. Process the selected option.
5. Display the corresponding story.
6. End the adventure.

## 6. How to Run the Project
1. Save the code as `adventure_game.c`.
2. Compile using: `gcc adventure_game.c -o adventure`
3. Run the generated program.

## 7. Expected Output
The program displays an adventure story and responds to the player's choices with different outcomes.

## 8. Conclusion
The project demonstrates how conditional statements and user input can be used to create an interactive game using C.
