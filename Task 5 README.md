# Simple Calendar Application Using C

## 1. Project Overview
The Simple Calendar Application is a console-based program developed using C. It displays the calendar for a selected month and year.

## 2. Objectives
- Display monthly calendars.
- Accept month and year from users.
- Calculate the correct weekday arrangement.
- Handle leap years.

## 3. Tools & Technologies Used
- C Programming Language
- GCC Compiler
- VS Code / Code::Blocks
- Command Prompt / Terminal

## 4. Features Implemented
- Month selection
- Year selection
- Monthly calendar display
- Leap-year calculation
- Correct weekday arrangement

## 5. Application Workflow
1. Start the application.
2. Enter a month and year.
3. Validate the entered values.
4. Calculate the number of days.
5. Determine the starting weekday.
6. Display the calendar.

## 6. How to Run the Project
1. Save the code as `simple_calendar.c`.
2. Compile using: `gcc simple_calendar.c -o calendar`
3. Run the generated program.

## 7. Expected Output
The program displays the selected month's calendar with the correct dates and weekday arrangement.

## 8. Conclusion
The project demonstrates date calculations, leap-year handling, and calendar generation using C.
